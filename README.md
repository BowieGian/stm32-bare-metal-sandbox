# STM32 Bare-Metal Sandbox

A self-directed development environment utilizing the **STM32H747I-DISCO** Discovery Board to explore the fundamentals of the STM32H747XIH6 microcontroller and learn low-level register configuration on its dual-core architecture.

## Peripherals Implemented
*   **GPIO:** Configured pin modes, speeds, and states to interface with input buttons and drive output LEDs.
